# Módulo Python – Fundamentos de Ciencia de Datos

Este repositorio contiene ejercicios y módulos prácticos de Python orientados a análisis de datos y fundamentos de programación.

## Estructura

- 📁 `Estadistica`: cálculo de medidas de tendencia central y dispersión.
- 📁 `Numpy`: operaciones con arrays.
- 📁 `Pandas`: manejo de DataFrames.
- 📁 `OOP`: fundamentos de programación orientada a objetos.
- 📁 `Ficheros`: lectura y escritura de archivos.
- 📁 `Notebooks`: recopilación de prácticas interactivas.

## Requisitos

- Python 3.x
- Jupyter Notebook

## Uso

1. Clona este repositorio.
2. Abre los notebooks con Jupyter para explorar cada tema de forma práctica.
